Git & GitHub — The Everyday Loop
git status
git add .
git commit -m "message"
git pull --rebase
git push
  • git status — Check your working tree.
  • git add . — Stage changes under the current directory.
  • git commit -m "message" — Save staged changes as a commit.
  • git pull --rebase — Integrate upstream changes before pushing.
  • git push — Upload your commits to the configured upstream branch.
